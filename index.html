Full Backup

Captures the database, uploaded project files, company document files, Knowledge Hub documents, and the rotating backup snapshots into one new timestamped folder on your Desktop — the most complete recovery point the app can produce. Full Restore validates checksums, the database, and every referenced attachment before replacing anything, and first creates a complete safety backup of the current data. Client secrets use Windows DPAPI and remain decryptable only under the Windows account that encrypted them.

Moving to another PC or Windows account? The full bundle carries all ordinary data and documents. Client passwords and secret keys are protected by Windows DPAPI, so for full credential recovery restore under the same Windows account. Otherwise, plan to re-enter those secrets.
Recovery Readiness

Checks the live database, every rotating snapshot, referenced document files, search index, disk headroom, schema version, and credential portability. Read-only and safe to run.

Backups

Auto-rotated snapshots taken on launch (newest 5 kept). Restoring replaces the live database and restarts the app — a safety copy of the current data is always taken first.

Integrity Check

Read-only — checks the database file for structural corruption and dangling foreign keys. Safe to run any time.

Lookup Duplicates

Case-insensitive label collisions (e.g. "Acme" / "ACME") within Companies, Systems, or Natural — the same class of duplicate a past migration cleaned up once already. Merging moves every reference onto the kept code and removes the duplicate.

Orphan File Sweep

Runs automatically on every launch — removes leftover file folders for projects/documents that no longer exist. Shown below is what the most recent launch found.

How This App Thinks

Three ideas explain almost everything else in this app.

A Task is the durable thing — its name, company/system, and status.
A Session is one stretch of time on one date, logged against a task — a task can have many, across many days.
A Task's container is optional and exclusive — a Project (client/system work), a Department (internal work), or neither. Never both.
Continue something you worked on recently
Click its chip in the Continue strip at the top of Timesheet → fill in Time Type, Natural, Minutes → Save.
Start brand-new client/system work
+ Add Record → New Task → Company, System, Status, Description → Save. Project link and Sources are optional — tucked under More options.
Wrap up something you finished
Click the ✓ button on its row or card — no dropdown, no modal. Sets it Done immediately (undoable).
