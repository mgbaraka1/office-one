How This App Thinks

Three ideas explain almost everything else in this app.

A Task is the durable thing — its name, company/system, and status.
A Session is one stretch of time on one date, logged against a task — a task can have many, across many days.
A Task's container is optional and exclusive — a Project (client/system work), a Department (internal work), or neither. Never both.
Continue something you worked on recently
Click its chip in the Continue strip at the top of Timesheet → fill in Time Type, Natural, Minutes → Save.
Start brand-new client/system work
+ Add Record → New Task → Company, System, Status, Description → Save. Project link and Sources are optional — tucked under More options.
Wrap up something you finished
Click the ✓ button on its row or card — no dropdown, no modal. Sets it Done immediately (undoable).
